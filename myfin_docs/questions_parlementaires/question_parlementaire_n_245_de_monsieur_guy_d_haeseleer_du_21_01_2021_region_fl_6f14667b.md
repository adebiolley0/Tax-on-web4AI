# Question parlementaire n° 245 de monsieur Guy D'haeseleer du 21.01.2021 (Région flamande)

Question parlementaire n° 245 de monsieur Guy D'haeseleer du 21.01.2021 (Région flamande)

Vlaams parlement, Schriftelijke vragen, 2020-2021, websitepublicatie d.d. 15.03.2021

Verkeersbelasting - Kampeerwagens

(Ce texte n’existe qu’en néerlandais )

VRAAG

Wie een mobilhome aanschaft, betaalt jaarlijks verkeersbelasting op basis van de maximum toegelaten massa (MTM).

1. Kan de minister meedelen voor hoeveel mobilhomes in 2020 verkeersbelasting werd betaald? Graag de cijfers opgesplitst per categorie en naargelang de belasting betaald werd door natuurlijke personen dan wel rechtspersonen.

2. Wat was de totale opbrengst van deze verkeersbelasting in 2020?

3. Kan de minister deze gegevens ook bezorgen indien het gaat om leasingfirma’s?

4. Welke initiatieven neemt de minister in dit verband?

# Question parlementaire n° 165 de monsieur Olivier de Clippele du 15.03.2017 (Région de Bruxelles-Capitale)

Questions et Réponses, Parlement Région de Bruxelles-Capitale, 2016-2017, n° 28 du 15.04.2017, p. 116

Le respect du délai pour le dépôt des déclarations de succession

QUESTION

Je me réfère à l’article 40, § 1er, du Code des droits de succession qui précise que : « Le délai pour le dépôt de la déclaration de succession est de quatre mois à compter de la date du décès, si celui-ci est survenu dans le Royaume, de cinq mois, si le décès est survenu dans un autre pays d’Europe, et de six mois, si le décès est survenu hors d’Europe . »

Puis-je connaitre le nombre de déclarations qui ont été déposées dans le délai de quatre mois pour les décès survenus en Belgique, cinq mois pour les décès survenus en Europe et six mois pour les décès survenus en dehors d’Europe, et le nombre de déclarations qui ont été déposées après ces délais de rigueur, en précisant celles qui ont fait l’objet d’une autorisation administrative de report pour le dépôt de la déclaration et celles qui ont fait l’objet d’une amende pour dépôt tardif.

RÉPONSE

Nombre de déclarations déposées dans le délai respectif de 4, 5 ou 6 mois :

2014 : 2.987

2015 : 3.019

2016 : 2.963

Nombre de déclarations déposées hors délai, mais dans le délai prolongé :

2014 : 608

2015 : 546

2016 : 530

Nombre de déclarations déposées hors délai ayant fait l’objet d’une amende pour dépôt tardif :

2014 : 2.420

2015 : 2.325

2016 : 1.950

Nombre de déclarations déposées hors délai n’ayant pas fait l’objet d’une amende pour dépôt tardif :

2014 : 2.577

2015 : 2.505

2016 : 2.312

# Circulaire n° 16/2004 (Dos E.L.T.T. 67) du 22.11.2004

Circulaire n° 16/2004 (Dos E.L.T.T. 67) du 22.11.2004

Taxe sur l'épargne à long terme

I. Introduction.

Les circulaires n° 19 du 14 octobre 1994 et n° 24 du 29 octobre 1999 ont défini les directives selon lesquelles doivent être transmis sur support magnétique les relevés que les redevables de la taxe sur l'épargne à long terme sont tenus de dresser pour les contrats d'assurances ou les comptes épargne pour lesquels ils ont acquitté la taxe précitée au cours de l'année civile qui précède.

A partir du 1er janvier 2005, une nouvelle procédure est d'application, dans laquelle l'état annuel doit être introduit via une liaison Internet sécurisée. A partir de ce moment, il ne sera plus permis d'envoyer ces états par support magnétique. Après le 31 décembre 2004, ils seront refusés.

II. Description de la nouvelle procédure.

A partir du 1er janvier 2005, les banques, sociétés d'assurances et autres institutions doivent transmettre au SPF Finances les états des comptes ou contrats pour lesquels une taxe sur l'épargne à long terme doit être payée via une liaison Internet sécurisée.

La nouvelle application est accessible via le site portail du SPF Finances à l'adresse: http://www.minfin.fgov.be/

La déclaration peut être introduite de deux manières :

- soit via un formulaire : sur ce formulaire, peuvent être encodées et ensuite transmises les données par compte épargne ou contrat d'assurance sur la vie. Cette possibilité est prévue pour les institutions ayant peu de comptes épargne ou de contrats d'assurance sur la vie.
- soit via l'envoi d'un fichier au format XML: ce fichier doit être créé par l'institution elle-même avant l'envoi, en suivant la structure du schéma XSD disponible via le site portail du SPF Finances à l'adresse http://www.minfin.fgov.be/ . La nouvelle application contient un module de conversion au moyen duquel il est possible de convertir un fichier créé selon les anciennes directives (aussi bien en ASCII qu'en EBCDIC) dans le format XML. Le fichier XML généré est stocké sur le PC de l'utilisateur et peut ensuite être envoyé au SPF Finances. Les utilisateurs peuvent suivre le traitement de leurs déclarations grâce à un accusé de réception (envoyé dès réception de la déclaration) et un courriel (après traitement de la déclaration).

III. Prérequis.

1. Certificat digital de classe 3

Chaque utilisateur doit disposer personnellement d'un certificat digital de classe 3. Ce certificat permet au SPF Finances de vérifier l'identité de l'utilisateur. De plus, l'utilisateur peut alors signer les données digitales envoyées. Un tel certificat peut être obtenu auprès des organismes de certification suivants :

- Isabel : www.isabel.be
- GlobalSign : http://www.globalsign.net/
- Certipost : http://www.certipost.be/

2. Droits d'administrateur sur le PC

Lors de la première utilisation de l'application, l'utilisateur doit disposer des droits d'administrateur pour son PC, afin de permettre la copie d'un fichier sur le disque dur.

3. Communication du nom des utilisateurs mandatés

Le nom des personnes mandatées pour introduire les données dans la nouvelle application (les utilisateurs) doit être communiqué au SPF Finances. Cela peut se faire par courriel mentionnant le numéro d'entreprise de l'institution pour laquelle l'utilisateur concerné est mandaté, ainsi que le nom de cette personne. Ce nom doit être strictement identique à celui mentionné sur le certificat. Lors de chaque transmission de données ou annulation de déclaration, une vérification sera effectuée. Les personnes à contacter sont:

- Marc Van Vuchelen : marc.vanvuchelen@minfin.fed.be
- Marie-Roger Sonck : marie.sonck@minfin.fed.be

IV. Période de test.

Une version de test de la nouvelle application est disponible jusqu'au 31 décembre 2004 inclus, permettant aux banques, sociétés d'assurances et autres institutions d'adapter leur propre application à la nouvelle procédure.

Les données envoyées à titre de test ne seront pas conservées au-delà du 31 décembre 2004.

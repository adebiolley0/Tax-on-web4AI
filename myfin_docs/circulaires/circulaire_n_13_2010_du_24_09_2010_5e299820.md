# Circulaire n° 13/2010 du 24.09.2010

Circulaire n° 13/2010 du 24.09.2010

Plan et matrice cadastrale online via l'application URBAIN - Situation au 01.01.2010 - Communes

Service Public Fédéral FINANCES

DOCUMENTATION PATRIMONIALE

Service IV - Direction 1

Dossier n° KM/16.843

Annexes : 2

| 1. | PREAMBULE |  |
| --- | --- | --- |
| 1.1 | En application de l'article 22 de l'AR du 20 septembre 2002 qui fixe les rémunérations et les règles précises de délivrance des renseignements et extraits cadastraux (MB du 11.10.2002), les communes reçoivent annuellement un exemplaire du plan parcellaire cadastral et de la matrice cadastrale concernant leur territoire. |  |
| 1.2 | Jusqu'à la situation au 01.01.2009 incluse, tant le plan que la matrice cadastrale, ont été fournis aux communes sur Cd-Rom via les antennes du cadastre compétentes. Les informations relatives au revenu cadastral et à la contenance (jusqu'à la situation au 01.01.2009 incluse) étaient transmises directement aux administrations communales par la poste. |  |
| 1.3 | Depuis le lundi 16 août 2010, ces données sont mises en ligne à disposition des communes. La diffusion de masse sur Cd-Rom de la matrice cadastrale n° 212 AM et du plan parcellaire cadastral ainsi que l'envoi des statistiques sur papier ont été abandonnés. |  |
| 2. | EVOLUTION |  |
| 2.1 | Conformément à la réglementation relative à la protection des bases de données et à différents avis de la Commission pour la Protection de la Vie privée, la délivrance de l'information patrimoniale via Cd-Rom a été abandonnée au profit de la possibilité de téléchargement de ces fichiers. |  |
| 2.2 | Cette réorientation a aussi été adoptée pour les statistiques annuelles qui sont ainsi intégrées à cette nouvelle voie de diffusion de l'information. |  |
| 3. | TELECHARGEMENT DES DONNEES VIA L'APPLICATION URBAIN |  |
| 3.1 | A partir de la situation cadastrale au 01.01.2010, l'accès au plan parcellaire cadastral, à la matrice cadastrale et aux statistiques est octroyé via l'application déjà connue URBAIN ( URBA nistic I nformation N etwork). |  |
| 3.2 | Cette application a donc été adaptée à cet effet : le menu de gauche de la nouvelle page d'accueil URBAIN contient une rubrique supplémentaire "Téléchargement". Les manuels d'utilisation ont été revus pour reprendre les nouvelles fonctionnalités et sont également disponibles dans cette rubrique. |  |
| 3.3 | Les communes - qui acceptent les conditions de la licence (voir point 4.2 ci-après) - peuvent télécharger les fichiers suivants relatifs à leur territoire : |  |
|  | ° | la matrice cadastrale (y compris les fichiers des propriétaires et des parcelles) (Matrice.zip). La structure des fichiers .txt, ainsi que les modalités de recherche préprogrammées (Access) sont maintenues; |
|  | ° | le logiciel de visualisation de la matrice cadastrale (Matrice_doc.zip); |
|  | ° | le plan parcellaire cadastral (Plan.zip). Le GIS-viewer nécessite de disposer d'un PC avec un système d'exploitation Windows (95/98/2000/ME/NT/XP/Vista/7). Le produit est stand-alone . Aucune autre application GIS ou CAD n'est nécessaire; |
|  | ° | le logiciel de visualisation pour le plan cadastral (Plan_doc.zip); |
|  | ° | les statistiques (aussi appelées STATINFO) reprenant les totaux des différents revenus cadastraux et des contenances. Ces statistiques peuvent être imprimées pour les besoins du secrétaire communal (prévisions budgétaires). |
| 4. | MISE EN PRATIQUE DE LA NOUVELLE METHODE DE TRAVAIL |  |
| 4.1 | La manière de télécharger et de consulter les données et les informations est expliquée par un agent de l'antenne Mesures & Evaluations compétente lors d'une rencontre personnalisée avec un représentant de chaque commune (l'indicateur-expert ou toute autre personne mandatée par la commune). |  |
| 4.2 | Lors de cet entretien, et afin de garantir un usage correct de l'information cadastrale disponible, les conditions de la licence doivent être contresignées par le représentant susnommé de chaque commune ( voir copie annexe n° 1 ). |  |
| 4.3 | Si nécessaire, l'agent du cadastre fournit les informations utiles relatives à la procédure d'obtention d'un accès à l'application URBAIN et son fonctionnement. |  |
| 4.4 | Tous les manuels et les formulaires nécessaires à l'utilisation de URBAIN sont disponibles via l'application URBAIN (copie du formulaire de procuration, voir l'annexe n° 2 ). |  |
| 5. | PROMOUVOIR L'UTILISATION DE L'APPLICATION URBAIN |  |
| 5.1 | Les statistiques cadastrales font apparaître que l'application URBAIN n'est pas encore connue ou pas encore utilisée par certaines communes qui fournissent leurs listes 220 sous un autre format ou qui ne fournissent pas du tout de listes à l'Administration Mesures & Evaluations. |  |
| 5.2 | La mise à disposition des données cadastrales et des renseignements via l'application URBAIN constitue en tout cas un argument primordial pour convaincre les non-utilisateurs de cette application. |  |
| 5.3 | Ces données seront en effet immédiatement et en permanence disponibles, de plus le système offre la possibilité de disposer des situations antérieures (à partir du 01.01.2009). Aussi, faut-il attirer l'attention sur les avantages de cette information lors de l'établissement des budgets communaux. |  |
| 6. | SITUATION |  |
| 6.1 | Provisoirement, seule une situation annuelle sera publiée, à savoir la situation fiscale au 01 janvier de l'année d'imposition, base pour la perception du précompte immobilier. |  |
| 6.2 | Les prochaines situations au 01.01 seront ajoutées annuellement. |  |
| 7. | DISPOSITIONS DIVERSES |  |
| 7.1 | Les sociétés de prestations de service (ex. CIPAL) et les firmes externes (ex. EUROTRONICS SA) - avec lesquelles travaillent certaines communes pour le traitement de leurs données - ont été informées par l'administration centrale de la Documentation patrimoniale via courriel des présents développements. |  |
| 7.2 | Pour plus de clarté, il n'existe aucune différence entre l'information diffusée précédemment sur Cd_Rom et l'information téléchargée via le web. Par conséquent, il n'est pas nécessaire d'adapter les applications existantes. La commune peut confier les données aux services susnommés (voir point 7.1, ci-dessus) pour la mise à jour des données, à la condition de respecter les obligations telles qu'elles sont écrites dans la licence. |  |
| 7.3 | Le plan parcellaire cadastral ne sera plus délivré sur papier aux administrations communales que sur demande. Comme la volonté est de réduire fortement la délivrance des données sur papier, à partir de la situation au 01.01.2011, une rétribution sera facturée (conformément à l'AR du 20.09.2002, art. 10, 5°, le montant s'élève actuellement à 13,75 € par feuille de plan). |  |
| 7.4 | Pour toute question éventuelle ou remarque constructive relatives à la présente nouvelle manière de diffuser l'information, il est possible de contacter le helpdesk via comcel.patdoc@minfin.fed.be. |  |

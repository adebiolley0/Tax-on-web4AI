# Article 193 du Code des droits d'enregistrement - Législation fédérale

Article 193 du Code des droits d'enregistrement - Législation fédérale

Communication importante

Article 193 ( applicable depuis le 16.05.2014)

(modifié par l’art. 69 de la loi du 25 avr. 2014 (M.B., 16.05.2014)). Texte applicable depuis le 16 mai 2014 (art. 99) )

Ne peuvent être choisis ou nommés comme experts :

1  Les fonctionnaires de l’Administration générale de la documentation patrimoniale ;

2  Les officiers publics ou ministériels rédacteurs des actes ou déclarations ;

3  Les employés des dits fonctionnaires et officiers publics ou ministériels.

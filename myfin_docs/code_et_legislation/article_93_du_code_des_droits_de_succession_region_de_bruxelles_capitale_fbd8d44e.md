# Article 93 du Code des droits de succession – Région de Bruxelles-Capitale

Article 93 du Code des droits de succession – Région de Bruxelles-Capitale

Article 93 ( applicable à partir du 17.04.1936 )

Les frais des formalités hypothécaires relatives à l'hypothèque légale sont, dans tous les cas, à la charge de l'Etat.

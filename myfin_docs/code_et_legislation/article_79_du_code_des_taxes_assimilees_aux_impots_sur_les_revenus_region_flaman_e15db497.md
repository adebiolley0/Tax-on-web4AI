Article 79 du Code des taxes assimilées aux impôts sur les revenus - Région flamande

(le Code du 23 .11. 1965 des taxes assimilées aux impôts sur les revenus, tel qu'il s'applique sur la taxe sur les jeux et paris et sur la taxe sur les appareils automatiques de divertissement en ce qui concerne la Région flamande est abrogé par l’art. 5.0.0.0.1, 2° /1 du décret du 13 .12. 2013 (M.B., 23.12.2013), inséré par l’art 59 du décret du 0 7 .12. 2018 (M.B., 20.12.2018).

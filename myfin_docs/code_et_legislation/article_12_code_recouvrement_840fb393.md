# Article 12, Code Recouvrement

Article 12, Code Recouvrement

Art. 12 entre en vigueur le 01.01.2020 (art. 2 et 139, al. 1, L 13.04.2019 - M.B. 30.04.2019; Numac: 2019041000)

[Le Roi peut fixer pour chaque catégorie de créance une entrée en vigueur antérieure (art. 139, al. 2, L 13.04.2019 - M.B. 30.04.2019; Numac: 2019041000)]

L'administration ou l'organisme gestionnaire d'un bien de l'Etat, d'une Communauté ou d'une Région est responsable du paiement du précompte immobilier relatif à ce bien.

# Article 229/5, AR/CIR 92 (revenus 2026)

Art. 229/5 est applicable 10 jours après publication de la loi au Moniteur belge (19.07.2018) (art. 1, AR 29.06.2018 - M.B. 09.07.2018; Numac: 2018031468 )

L'échelle des amendes administratives concernant des infractions visées à l'article 445, § 3, du Code des impôts sur les revenus 1992, est fixée comme suit:

| Nature des infractions | Amende administrative |
| --- | --- |
| A. Infraction due à des circonstances indépendantes de la volonté du contribuable: | Néant |
| B. Infraction non imputable à la mauvaise foi ou à l'intention d'éluder l'impôt: |  |
| - 1re infraction: | Néant |
| - 2e infraction: | 1.250,00 euros |
| - 3e infraction: | 6.250,00 euros |
| - 4e infraction: | 12.500,00 euros |
| - Infractions suivantes: | 25.000,00 euros |
| C. Infraction due à la mauvaise foi ou à l'intention d'éluder l'impôt (y compris la remise de déclarations volontairement incomplètes ou inexactes): |  |
| - 1re infraction: | 12.500,00 euros |
| - Infractions suivantes: | 25.000,00 euros |

# Article 208 du Code des droits d'enregistrement - Région de Bruxelles-Capitale

Article 208 du Code des droits d'enregistrement - Région de Bruxelles-Capitale

CHAPITRE XIII - Restitution

Article 208 (applicable depuis le 01.02.1940)

Les droits régulièrement perçus ne peuvent être restitués, quels que soient les événements ultérieurs, sauf les cas prévus par le présent titre.

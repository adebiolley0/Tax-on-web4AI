# Article 230 du Code des droits d'enregistrement - Législation fédérale

Article 230 du Code des droits d'enregistrement - Législation fédérale

Communication importante

Article 230 ( applicable depuis le 01.02.1940 )

Il est dressé procès-verbal de la vente publique par l’officier public ou le fonctionnaire instrum entant.

Chaque objet adjugé est porté immédiatement à ce procès-verbal ; le prix y est écrit en toutes lettres et tiré hors ligne en chiffres.

Après chaque séance, le procès-verbal est clôturé et signé.

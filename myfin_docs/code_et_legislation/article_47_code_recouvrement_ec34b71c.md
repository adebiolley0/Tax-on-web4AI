# Article 47, Code Recouvrement

Article 47, Code Recouvrement

Art. 47 entre en vigueur le 01.01.2020 (art. 2 et 139, al. 1, L 13.04.2019 - M.B. 30.04.2019; Numac: 2019041000)

[Le Roi peut fixer pour chaque catégorie de créance une entrée en vigueur antérieure (art. 139, al. 2, L 13.04.2019 - M.B. 30.04.2019; Numac: 2019041000)]

L'avis visé à l'article 43 est établi conformément au modèle arrêté par le Roi.

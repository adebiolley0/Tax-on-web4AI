# Article 259 du Code des droits d'enregistrement - Région wallonne

Article 259 du Code des droits d'enregistrement - Région wallonne

TITRE II - DROIT D’HYPOTHEQUE

Article 259 ( applicable depuis le 01.12.2021)

(modifié par l’art. 5 de la loi du 26 nov. 2021 ( M.B. , 02.12.2021). Texte applicable depuis le 1 er déc. 2021 (art. 7))

Il est établi, sous le nom de droit d’hypothèque, un impôt sur les inscriptions d’hypothèques et de privilèges sur immeubles.

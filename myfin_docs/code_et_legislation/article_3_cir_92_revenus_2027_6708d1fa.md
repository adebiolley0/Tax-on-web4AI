# Article 3, CIR 92 (revenus 2027)

Art. 3 est applicable à partir de l'exercice d'imposition 2005 (art. 3 et 65, al. 5, L 10.08.2001 - M.B. 20.09.2001; Numac: 2001003402 )

Sont assujettis à l'impôt des personnes physiques les habitants du Royaume.

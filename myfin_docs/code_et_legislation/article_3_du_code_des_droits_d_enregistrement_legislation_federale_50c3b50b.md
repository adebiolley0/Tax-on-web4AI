# Article 3 du Code des droits d'enregistrement - Législation fédérale

Article 3 du Code des droits d'enregistrement - Législation fédérale

Communication importante

Article 3 ( applicable depuis le 30.07.2018 )

(modifié par l’art. 80 de la loi du 11 juil. 2018 (M.B., 20.07.2018 – éd. 2) . Texte applicable depuis le 30 juil. 2018 (art. -))

S’il est présenté à l’enregistrement un acte ou écrit rédigé dans une langue autre que les langues nationales, le bureau compétent de l’Administration générale de la Documentation patrimoniale peut exiger qu’il y soit annexé, a ux frais de la personne qui requiert la formalité, une traduction certifiée par un traducteur juré.

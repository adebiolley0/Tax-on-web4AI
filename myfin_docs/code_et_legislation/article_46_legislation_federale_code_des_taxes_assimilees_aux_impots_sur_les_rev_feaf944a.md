# Article 46 - Législation fédérale - Code des taxes assimilées aux impôts sur les revenus

Article 46 - Législation fédérale - Code des taxes assimilées aux impôts sur les revenus

Article 46

(modifié par l’art. 2 de l’arrêté royal du 30.12.1980 (M.B., 05.02.1981 – Numac : 1981000128) . Texte applicable à partir de l’exercice d’imposition 1982 (art. 3, 2°))

Il est perçu une taxe de 10 francs par bague pour pigeon vendue par les associations et fédérations agréées par le Ministre des Finances.

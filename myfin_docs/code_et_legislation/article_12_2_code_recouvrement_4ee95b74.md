# Article 12/2, Code Recouvrement

Article 12/2, Code Recouvrement

Art. 12/2 entre en vigueur le 07.01.2022 (M.B. 2 8 .12.20211; Numac: 2021034484)

Le recouvrement des impôts sur les revenus, établis dans le chef des sociétés visées à l'article 2, § 1er, 5°, a, alinéa 1er, deuxième tiret, du Code des impôts sur les revenus 1992, peut être poursuivi directement à charge des actionnaires ou associés, dans la mesure où ces impôts correspondent proportionnellement à la part de ces actionnaires ou associés dans le capital.

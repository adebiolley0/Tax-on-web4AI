# Article 3, Code Recouvrement

Article 3, Code Recouvrement

Art. 3 entre en vigueur le 01.01.2020 (art. 2 et 139, al. 1, L 13.04.2019 - M.B. 30.04.2019; Numac: 2019041000)

[Le Roi peut fixer pour chaque catégorie de créance une entrée en vigueur antérieure (art. 139, al. 2, L 13.04.2019 - M.B. 30.04.2019; Numac: 2019041000)]

Le receveur est chargé du recouvrement des créances fiscales et non fiscales.

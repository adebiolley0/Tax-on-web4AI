# Article 101, Code Recouvrement

Article 101, Code Recouvrement

Art. 10 1 entre en vigueur le 01.01.2025 (art.1 80 , L.26.01.2021 – M.B.10.02.2021 ; Numac : 2021040269)

Droit futur: Article 101 remplacé par la loi du 12.05.2024 (M.B. 30.05.2024 ; Numac : 2024003880). Entrée en vigueur: 01.01.2028

Les effets juridiques d'un message transmis au moyen d'une plateforme électronique sécurisée ou sous pli fermé sont les mêmes.

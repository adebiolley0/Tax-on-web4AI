# Article 25 du Code des taxes assimilées aux impôts sur les revenus - Région flamande

Article 25 du Code des taxes assimilées aux impôts sur les revenus - Région flamande

Article 25

(le Code du 23 .11. 1965 des taxes assimilées aux impôts sur les revenus, tel que d'application à la taxe de circulation sur les véhicules automobiles et à la taxe de mise en circulation en ce qui concerne la Région flamande est abrogé par l’art. 5.0.0.0.1, 2° du décret du 13 .12. 2013 (M.B., 23.12.2013). Texte applicable à partir de l’année d’imposition 2014 (art. 7.0.0.0.1))

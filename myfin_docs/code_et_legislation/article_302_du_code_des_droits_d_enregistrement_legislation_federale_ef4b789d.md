# Article 302 du Code des droits d'enregistrement - Législation fédérale

Article 302 du Code des droits d'enregistrement - Législation fédérale

Communication importante

Article 302 ( applicable depuis le 01.02.1940)

Sont enregistrés en débet les actes relatifs à l’exécution d’office des décisions des tribunaux arb itraux mixtes institués par les traités de paix.

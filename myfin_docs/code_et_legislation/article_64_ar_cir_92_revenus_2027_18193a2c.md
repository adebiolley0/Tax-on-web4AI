# Article 64, AR/CIR 92 (revenus 2027)

Art. 64 est applicable pour l'exercice d'imposition 2017 (art. 1 et 2 , AR 07.03.2016 - M.B. 09.03.2016; Numac: 2016003089 )

Conformément à l'article 162, alinéa 1 er , du Code des impôts sur les revenus 1992, le pourcentage de la majoration d'impôt est déterminé en fonction du taux de référence repris dans le tableau ci-après:

| Exercice d'imposition | Taux de référence |
| --- | --- |
| 1993 | 9 |
| 1996 | 7 |
| 2015 | 0,75 |
| 2016 | 0,50 |
| 2017 | 0,50 |

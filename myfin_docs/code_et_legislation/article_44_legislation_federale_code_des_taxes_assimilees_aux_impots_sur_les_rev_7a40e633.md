# Article 44 - Législation fédérale - Code des taxes assimilées aux impôts sur les revenus

Article 44 - Législation fédérale - Code des taxes assimilées aux impôts sur les revenus

Article 44

(remplacé par l’art. 2 de l’arrêté royal du 22.08.1980 (M.B., 02.09.1980 – Numac : 1980082202) . Texte applicable à partir du 01.09.1980 (art. 13, 1°))

Par dérogation à l’ article 43 , la taxe frappant les paris sur les courses de chevaux courues en Belgique est fixée comme suit :

1° un cinquième du prélèvement opéré sur le montant brut des sommes engagées dans le pari mutuel ;

2° 5 p.c. du montant brut des sommes engagées dans le pari à la cote.

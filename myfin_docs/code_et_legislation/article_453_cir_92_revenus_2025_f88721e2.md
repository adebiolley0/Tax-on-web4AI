# Article 453, CIR 92 (revenus 2025)

Art. 453 est applicable à partir de l'exercice d'imposition 1992 (art. 343, CIR; art. 1, AR 10.04.1992 - M.B. 30.07.1992; Numac: 1992003456 )

La violation du secret professionnel, tel qu'il est défini à l'article 337, sera punie conformément à l'article 458 du Code pénal.

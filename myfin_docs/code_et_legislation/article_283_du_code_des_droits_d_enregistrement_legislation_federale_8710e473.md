# Article 283 du Code des droits d'enregistrement - Législation fédérale

Article 283 du Code des droits d'enregistrement - Législation fédérale

Communication importante

CHAPITRE III - D ispositions diverses

Article 283 ( applicable depuis le 01.02.1940)

Dans les cas prévus à l’ article 160 , les droits de greffe sont liquidés en débet et recouvrés selon les règles applicables aux droits d’enregistrement liquidés dans les mêmes conditions.

# Article 92 du Code des droits de succession – Région de Bruxelles-Capitale

Article 92 du Code des droits de succession – Région de Bruxelles-Capitale

Article 92 ( applicable à partir du 17.04.1936 )

Il n'est pas préjudicié par le droit de privilège et d'hypothèque légale aux droits précédemment acquis à des tiers.

# Article 274 du Code des droits d'enregistrement – Région de Bruxelles-Capitale

Article 274 du Code des droits d'enregistrement – Région de Bruxelles-Capitale

Article 274 ( applicable depuis le 01.01.1961 – modification uniquement en néerlandais)

(seul le texte en néerl andais a été modifié par l’art. 312 de la loi du 27 déc. 2006 (M.B. 28.12.2006 – éd. 3 ))

Lorsque plusieurs arrêts, jugements ou actes sont reproduits dans une expédition, une copie ou un extrait, le droit est calculé par page de chacun de ces documents, sans qu'il puisse être perçu, pour chacun d'eux, moins que le droit dû pour une page.

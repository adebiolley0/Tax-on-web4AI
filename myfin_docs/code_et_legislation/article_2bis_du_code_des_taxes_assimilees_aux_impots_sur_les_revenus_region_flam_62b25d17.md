# Article 2bis du Code des taxes assimilées aux impôts sur les revenus - Région flamande

Article 2bis du Code des taxes assimilées aux impôts sur les revenus - Région flamande

Article 2 bis

( modifié par l’art. 16 du décret du 9 juil. 2010 (M.B., 28.07.2010). Texte applicable par l’art. 26 de l’arrêté du Gouvernement flamand du 10 .12. 2010 (M.B., 03.02.2011), soit le 01.01. 2011 (art. 75)) ( 1 )

Dans les limites prévues par la loi, le montant des amendes administratives proportionnelles prévues par le présent Code ou par les arrêtés pris pour son exécution , est fixé selon une échelle dont les graduations sont déterminées par le Gouvernement flamand .

----------

Note :

(1) le présent article, tel qu'il s'applique sur la taxe sur les jeux et paris et sur la taxe sur les appareils automatiques de divertissement en ce qui concerne la Région flamande est abrogé par l’art. 5.0.0.0.1, 2°/1 du Code flamand de la Fiscalité du 13.12.2013 (M.B., 23.12.2013).

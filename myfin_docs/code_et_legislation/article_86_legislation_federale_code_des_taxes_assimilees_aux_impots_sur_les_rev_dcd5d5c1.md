# Article 86 - Législation fédérale - Code des taxes assimilées aux impôts sur les revenus

Article 86 - Législation fédérale - Code des taxes assimilées aux impôts sur les revenus

Article 86

Sauf s'ils ont été détruits à la suite d'un sinistre et que la preuve irréfutable de la destruction est apportée, les signes distinctifs fiscaux ne sont remplacés que lorsqu'ils sont restitués et que leur identification est possible.

# Article 84, Code de la TVA

Article 84

( T exte actuel, à partir du 06.04.1999 ) [ historique ]

La solution des difficultés qui peuvent s'élever relativement à la perception de la taxe avant l'introduction des instances appartient au Ministre des Finances.

Le Ministre des Finances conclut les transactions avec les redevables, pourvu qu'elles n'impliquent pas exemption ou modération d'impôt.

Dans les limites prévues par la loi, le montant des amendes fiscales proportionnelles prévues par le présent Code ou par les arrêtés pris pour son exécution, est fixé selon une échelle dont les graduations sont déterminées par le Roi.

Article 84

(Le texte de l’art. 84 , est modifié à partir du 01.02.1987 (A rt. 73, L 04.08.1986) )

La solution des difficultés qui peuvent s'élever relativement à la perception de la taxe avant l'introduction des instances appartient au Ministre des Finances.

Le Ministre des Finances statue sur les requêtes ayant pour objet la remise des amendes fiscales et conclut les transactions avec les redevables, pourvu qu'elles n'impliquent pas exemption ou modération d'impôt.

Dans les limites prévues par la loi, le montant des amendes fiscales proportionnelles prévues par le présent Code ou par les arrêtés pris pour son exécution, est fixé selon une échelle dont les graduations sont déterminées par le Roi.

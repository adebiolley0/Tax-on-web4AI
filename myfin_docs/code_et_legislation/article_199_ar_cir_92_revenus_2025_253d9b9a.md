# Article 199, AR/CIR 92 (revenus 2025)

Art. 199 est applicable à partir de l'exercice d'imposition 1992 (art. 163, AR/CIR; AR 27.08.1993 – M.B. 13.09.1993; Numac: 1993082751 )

La période imposable coïncide avec l'année dont le millésime désigne l'exercice d'imposition, pour l'application:

a) du précompte immobilier;

b) du précompte mobilier;

c) du précompte professionnel visé aux articles 270 à 275 du Code des impôts sur les revenus 1992.

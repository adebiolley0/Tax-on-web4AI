# Article 89 - Législation fédérale - Code des taxes assimilées aux impôts sur les revenus

Article 89 - Législation fédérale - Code des taxes assimilées aux impôts sur les revenus

CHAPITRE VI – Sanctions et dispositions pénales

Article 89

(modifié par l’art. 18 de l’arrêté royal du 18.04.1967 (M.B., 20.04.1967 – Numac : 1967041816) . Texte applicable à partir du 01.05.1967 (art. 20))

En cas d’absence de paiement, le redevable peut être imposé d’office, sauf le droit de réclamation et de recours.

La taxe éludée est portée au quintuple.

La taxe établie d’office est payable immédiatement.

Cette taxe peut être établie dans un délai de trois ans, à partir du 1 er janvier de l’exercice d’imposition pour lequel elle est due.

# Article 25 - Législation fédérale - Code des taxes assimilées aux impôts sur les revenus

Article 25 - Législation fédérale - Code des taxes assimilées aux impôts sur les revenus

Article 25

Le jour de l’entrée des véhicules et celui de leur sortie sont comptés chacun pour un jour. Toutefois, lorsqu’ils ne sont séparés que par un jour intermédiaire, le jour de sortie n'est pas compté.

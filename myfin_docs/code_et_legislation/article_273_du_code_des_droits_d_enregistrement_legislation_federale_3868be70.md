# Article 273 du Code des droits d'enregistrement - Législation fédérale

Article 273 du Code des droits d'enregistrement - Législation fédérale

Communication importante

Article 273 ( applicable depuis le 01.01.1961 – modification uniquement en néerlandais)

( seul le texte en néerl andais a été modifié par l’art. 312 de la loi du 27 déc. 2006 (M.B., 28.12.2006 – éd. 3) )

Le droit est calculé par page, de l'arrêt, du jugement ou de l'acte, reproduite dans l'expédition, la copie ou l'extrait.

Toutefois, le droit est calculé uniformément à raison d'une page pour les ext raits délivrés en exécution de l'article 121 du Règlement général sur les frais de justice en matière répressive.

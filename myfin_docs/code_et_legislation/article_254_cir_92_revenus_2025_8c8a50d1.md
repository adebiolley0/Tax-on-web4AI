# Article 254, CIR 92 (revenus 2025)

Art. 254 est applicable à partir de l'exercice d'imposition 1992 (art. 158, CIR; art. 1, AR 10.04.1992 - M.B. 30.07.1992; Numac: 1992003456 )

L'exercice d'imposition au précompte immobilier est désigné par le millésime de l'année dont les revenus servent de base audit précompte.

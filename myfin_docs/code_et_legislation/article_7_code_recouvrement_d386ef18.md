# Article 7, Code Recouvrement

<span id="ms-rterangecursor-start" RteNodeId="1"></span><span id="ms-rterangecursor-end"></span>Article 7, Code Recouvrement

Art. 7 entre en vigueur le 01.01.2020 (art. 2 et 139, al. 1, L 13.04.2019 - M.B. 30.04.2019; Numac: 2019041000)

[Le Roi peut fixer pour chaque catégorie de créance une entrée en vigueur antérieure (art. 139, al. 2, L 13.04.2019 - M.B. 30.04.2019; Numac: 2019041000)]

Le rôle et le registre de perception et recouvrement sont aussi exécutoires contre les codébiteurs.

# Article 25, Code de la TVA

Article 25

( T exte actuel, à partir du 01.01. 1993 ) [ historique ]

Toute personne est présumée, jusqu'à preuve du contraire, avoir importé en Belgique les biens qu'elle a acquis dans un pays tiers ou dans un territoire tiers, ainsi que les biens qui ont fait l'objet d'un travail pour son compte dans un pays tiers ou dans un territoire tiers.

Article 25 ( version actuelle )

( Le texte de l’art. 25 , est modifié à partir du 01.01.1993 (Art. 25, L 28.12.1992) )

Toute personne est présumée, jusqu'à preuve du contraire, avoir importé en Belgique les biens qu'elle a acquis dans un pays tiers ou dans un territoire tiers, ainsi que les biens qui ont fait l'objet d'un travail pour son compte dans un pays tiers ou dans un territoire tiers.

[ Top ]

Article 25

(Le texte de l’art. 25, est inséré à partir du 01.01.1971 ( L 03.07.1969) )

Toute personne est présumée, jusqu'à preuve du contraire, avoir importé les biens qu'elle a acquis à l'étranger, ainsi que les biens qui ont fait l'objet à l'étranger d'un travail pour son compte.

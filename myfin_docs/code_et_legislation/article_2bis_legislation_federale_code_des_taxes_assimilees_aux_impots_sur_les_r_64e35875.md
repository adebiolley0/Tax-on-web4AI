# Article 2bis - Législation fédérale - Code des taxes assimilées aux impôts sur les revenus

Article 2bis - Législation fédérale - Code des taxes assimilées aux impôts sur les revenus

Article 2 bis

( inséré par l’ art. 65 de la loi du 04.08.1986 (M.B., 20.08.1986 – Numac : 1986003953) . Texte applicable à partir du 01.02.1987 (art. 116) )

Dans les limites prévues par la loi, le montant des amendes administratives proportionnelles prévues par le présent Code ou par les arrêtés pris pour son exécution , est fixé selon une échelle dont les graduations sont déterminées par le Roi.

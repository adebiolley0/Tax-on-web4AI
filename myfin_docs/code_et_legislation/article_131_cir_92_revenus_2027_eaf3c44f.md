# Article 131, CIR 92 (revenus 2027)***

Art. 131, alinéa 1, entre en vigueur le 31.12.2026 et est applicable à partir de l'exercice d'imposition 2028 (art. 2, 2°, et 4, al. 2, L 15.07.2026 - M.B. 29.07.2026; Numac: 2026005724 )

Pour le calcul de l'impôt, un montant de base de 4.990 euros (montant de base) est exempté d'impôt.

Ce montant est majoré de 870 euros (montant de base) lorsque le contribuable est atteint d'un handicap.

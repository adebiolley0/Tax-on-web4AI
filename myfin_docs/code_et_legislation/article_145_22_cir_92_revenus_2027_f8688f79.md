# Article 145^22, CIR 92 (revenus 2027)

Art. 145 22 est applicable à partir de l'exercice d'imposition 1995 (art. 8, L 30.03.1994 - M.B. 31.03.1994; Numac: 1994003236 )

Le Roi détermine les conditions auxquelles les dépenses visées à l'article 145 21 doivent satisfaire pour être prises en considération pour la réduction d'impôt.

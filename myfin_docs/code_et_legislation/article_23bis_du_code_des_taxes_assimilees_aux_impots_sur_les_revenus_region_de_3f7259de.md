# Article 23bis du Code des taxes assimilées aux impôts sur les revenus - Région de Bruxelles-Capitale

Article 23bis du Code des taxes assimilées aux impôts sur les revenus - Région de Bruxelles-Capitale

Article 23 bis

(modifié par l’art. 11 de l’ordonnance du 28.11.2019 (M.B., 10.12.2019 – Numac : 2019042688 ) . Texte applicable à partir du 01.01.2020 . Ses dispositions sont d'application à partir de l'exercice d'imposition 2020 (art. 18))

Lorsqu’au cours d’un exercice d’imposition un véhicule cesse d’être inscrit au répertoire matricule ou fait l’objet d’une exonération, la taxe payée est restituée à concurrence des mois non écoulés ou, dans la même limite, est imputée sur la taxe due par le redevable pour un autre véhicule.

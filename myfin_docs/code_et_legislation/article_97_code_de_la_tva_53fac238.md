# Article 97, Code de la TVA

Article 97

( T exte actuel, à partir du 01.01. 1971 ) [ historique ]

Les dispositions antérieures à l'entrée en vigueur du présent Code qui, pour l'application des lois fiscales, assimilent à l'Etat certaines personnes morales de droit public et certains services publics, ne sont pas applicables en ce qui concerne la taxe établie par ce Code.

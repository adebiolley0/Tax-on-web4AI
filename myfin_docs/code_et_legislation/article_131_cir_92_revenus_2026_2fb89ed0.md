# Article 131, CIR 92 (revenus 2026)***

Art. 131, alinéa 1, est applicable à partir de l'exercice d'imposition 2027 (art. 2, 1°, et 4, al. 1, L 15.07.2026 - M.B. 29.07.2026; Numac: 2026005724 )

[montants indexés - revenus 2026 - Indexation automatique - exercice d'imposition 2027 ]

Pour le calcul de l'impôt, un montant de base de 11.550 euros (montant indexé) est exempté d'impôt.

Ce montant est majoré de 2.030 euros (montant indexé) lorsque le contribuable est atteint d'un handicap.

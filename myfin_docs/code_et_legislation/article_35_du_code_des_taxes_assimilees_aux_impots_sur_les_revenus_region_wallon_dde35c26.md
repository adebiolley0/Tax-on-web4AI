# Article 35 du Code des taxes assimilées aux impôts sur les revenus - Région wallonne

Article 35 du Code des taxes assimilées aux impôts sur les revenus - Région wallonne

Article 35

(modifié par l’art. 21 du décret du 28.11.2013 (M.B., 18.12.2013 – éd. 2 – Numac : 2013206976) . Texte applicable à partir du 01.01.2014 (art. 56))

Le service désigné par le Gouvernement wallon peut charger les organismes agréés pour le contrôle technique automobile de :

1° La constatation de données techniques spécifiques lors du contrôle technique automobile, pour autant qu’elles sont nécessaires pour la détermination de l’impôt ;

2° La communication des données visées au point 1° à la Direction pour l’Immatriculation des Véhicules.

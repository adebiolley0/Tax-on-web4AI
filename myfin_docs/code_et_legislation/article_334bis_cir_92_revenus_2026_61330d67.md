# Article 334bis, CIR 92 (revenus 2026)

Art. 334bis est applicable à partir du 01.01.1993 (art. 63, L 06.07.1994 - M.B. 16.07.1994; Numac: 1994003443 )

Les investigations visées au présent chapitre peuvent être effectuées par des agents d'autres administrations fiscales. Le Roi désigne ces administrations et, s'Il le juge nécessaire, les agents.

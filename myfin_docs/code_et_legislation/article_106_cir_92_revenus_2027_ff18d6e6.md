# Article 106, CIR 92 (revenus 2027)

Art. 106 est applicable à partir de l'exercice d'imposition 1992 (art. 71, CIR; art. 72, CIR; art. 1, AR 10.04.1992 - M.B. 30.07.1992; Numac: ; Numac: 1992003456 )

Le Roi détermine le mode d'imputation des dépenses sur les différentes catégories de revenus.

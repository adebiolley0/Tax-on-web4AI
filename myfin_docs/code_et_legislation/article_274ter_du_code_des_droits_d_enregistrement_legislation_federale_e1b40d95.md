# Article 274ter du Code des droits d'enregistrement - Législation fédérale

Article 274ter du Code des droits d'enregistrement - Législation fédérale

Communication importante

Article 274 ter ( applicable depuis le 08.07.2012)

(modifié par l’art. 104 de la loi du 22 juin 2012 (M.B., 28 .06.2012). Texte applicable depuis le 8 juil. 2012 (art. -))

Les droits dus sur une même demande pour une même affaire ne peuvent excéder 1450 euros.

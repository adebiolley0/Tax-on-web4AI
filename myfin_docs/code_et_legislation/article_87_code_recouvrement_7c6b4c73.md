# Article 87, Code Recouvrement

Article 87, Code Recouvrement

Art. 87 entre en vigueur le 01.01.2020 (art. 2 et 139, al. 1, L 13.04.2019 - M.B. 30.04.2019; Numac: 2019041000)

[Le Roi peut fixer pour chaque catégorie de créance une entrée en vigueur antérieure (art. 139, al. 2, L 13.04.2019 - M.B. 30.04.2019; Numac: 2019041000)]

Celui qui fera un faux témoignage, l'interprète ou l'expert qui fera une fausse déclaration, celui qui subornera un ou plusieurs témoins, experts ou interprètes dans l'un des cas d'enquête autorisés par les articles 74 à 76, sera puni conformément aux dispositions des articles 220 à 224 du Code pénal.

# Article 23 du Code des taxes assimilées aux impôts sur les revenus - Région wallonne

Article 23 du Code des taxes assimilées aux impôts sur les revenus - Région wallonne

Art icle 23

(remplacé par l’art. 11 de la loi du 25.01.1999 (M.B., 19.02.1999 – Numac : 1999003046) . Texte applicable à partir du 01.01.2000 (art. 18 ) )

Lorsque les conditions justifiant une exemption ne sont plus réunies au cours d’un exercice d’imposition, la taxe est due à concurrence des mois non écoulés.

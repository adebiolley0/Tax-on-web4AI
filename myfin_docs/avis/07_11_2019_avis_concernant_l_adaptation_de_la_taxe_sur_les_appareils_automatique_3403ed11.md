# 07.11.2019 - Avis concernant l'adaptation de la taxe sur les appareils automatiques de divertissement conformément à l'article 80, § 1er, du Code des taxes assimilées aux impôts sur les revenus - Nouveaux taux à partir du 01.01.2020

07.11.2019 - Avis concernant l'adaptation de la taxe sur les appareils automatiques de divertissement conformément à l'article 80, § 1er, du Code des taxes assimilées aux impôts sur les revenus. - Nouveaux taux à partir du 01.01.2020

( M.B. , 13.11.2019, p. 105572)

REGION DE BRUXELLES-CAPITALE

A partir du 1 er janvier 2020, le montant de la taxe sur les appareils automatiques de divertissement est fixé comme suit:

| Catégorie des appareils | Montant de l'impôt |
| --- | --- |
| A | 5.038,50 EUR |
| B | 1.457,30 EUR |
| C | 395,40 EUR |
| D | 282,50 EUR |
| E | 169,50 EUR |

Coefficient utilisé:

indice des prix à la consommation juin 2019 (base 2013)/indice des prix à la consommation juin 2011 (base 2013)

= 108,87/96,37 = 1,1297 .

Bruxelles, le 7 novembre 2019.

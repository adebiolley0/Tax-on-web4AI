# Numéro S 54-VL/01-03

Numéro S 54-VL/01-03

Répertoire RJ - Droits de succession

RÉGION FLAMANDE

Numéro S 54-VL/01-03

01. – Donations par actes enregistrés dans les trois ans précédant le décès (combinaison des art. 54 et 66 bis) .

03. - Lorsque de nombreux ayants droit sont imposés au tarif« entre autres personnes » et que le calcul des droits s'effectue donc globalement, pour appliquer l' article 54 C. succ . Fl. , deux liquidations distinctes doivent toujours avoir lieu. Une dans le chef de l'ayant droit handicapé comme s'il était seul imposé au tarif «entre autres personnes» et une seconde pour connaître les droits des autres ayants droit à imposer dans la catégorie « entre autres personnes ». Lors de cette liquidation, l'ayant droit handicapé doit être compris tout comme s'il n'était pas taxé séparément.

Dans l'hypothèse où l'ayant droit handicapé a également reçu des donations telles que celles visées à l' article 42, VIII bis , ces donations doivent être, dans le cadre de l' article 66 bis , comptabilisées dans les deux liquidations pour garantir la progressivité de l'impôt.

Exemple :

Succession de X, avec un actif net de 150.000 EUR, attribuée à trois étrangers A (44 ans et handicapé), B et C chacun pour 1/3 ou chacun 50.000 EUR. A bénéficie en vertu de l' article 54 d'un abattement de 1.000 x 14 = 14.000 EUR. Dans les 3 ans précédant le décès, X a fait à A une donation de 30.000 EUR sur laquelle le droit d'enregistrement de donation a été perçu.

Droits dus par A :

Base imposable par application de l' article 66 bis :

| 50.000 + 30.000 = | 80.000 EUR |
| --- | --- |

| 30.000 | déjà imposés |  |
| --- | --- | --- |
| 45.000 x 45 % = | 20.250 EUR |  |
| 5.000 x 55 % = | 2.750 EUR |  |
| 80.000 | 23.000 EUR |  |
| Exemption art. 54 - | 6.300 EUR | (14.000 x 45 %) |
|  | 16.700 EUR |  |

Droits dus à charge de B et de C

Somme des parts successorales nettes de A, B et C par application de l' article 66 bis : A (50.000 + 30.000) + B (50.000) + C (50.000) = 180.000 EUR

| 30.000 | déjà imposés |
| --- | --- |
| 45.000 x 45 % = | 20.250 EUR |
| 50.000 x 55 % = | 27.500 EUR |
| 55.000 x 65 % = | 35.750 EUR |
| 180.000 | 83.500 EUR |

dont pour B et C chacun 1/3 soit 27.833,34 EUR

D'autre part, lorsque dans l'exemple ce n'est pas A mais B ou C qui ont reçu la donation de 30.000 EUR visée à l' article 66 bis , la base imposable de cette donation en faveur de B ou de C ne doit donc pas être comprise dans la part successorale de A pour le calcul des droits dans le chef de A, handicapé. Ceci est la conséquence du texte décrétal qui stipule que la liquidation dans son chef doit être établie « comme s'il était la seule personne à qui revient sa part nette ».

Dans l'exemple précédent, les droits dus dans le chef de B et de C restent donc les mêmes, mais il est dû par A :

| 50.000 x 45 % = | 22.500 EUR |  |
| --- | --- | --- |
| article 54 - | 6.300 EUR | (14.000 x 45 %) |
|  | 16.200 EUR |  |

(Décision du 29.04.2003 - EE/99.600)

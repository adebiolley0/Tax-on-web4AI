# Numéro E 19/03-22

Numéro E 19/03-22

Répertoire RJ – Droits d’enregistrement, d’hypothèque et de greffe

Numéro E 19/03-22

03. – Acte translatif - C lause de réméré - D élai.

22. - L'exercice d'une clause de réméré n'est pas un acte translatif dans la mesure où les conditions légales sont remplies. La clause contenant un droit de réméré peut s'appuyer sur le code civil et aussi sur les lois spéciales comme par exemple la loi d'expansion économique (30 décembre 1970) ou sur le Code du logement flamand pour les ventes effectuées par les sociétés de logement social.

En ce qui concerne la loi d'expansion économique, il a déjà été jugé que le délai maximum de 5 ans prévu à l' article 1660 dans le Code civil ne s'applique pas (Cass. , 18 mars 2004, T. Not. , 2004, p. 374) et ceci malgré le fait que la loi d'expansion économique ne comporte elle-même aucun délai.

L' article 84 du Code flamand du logement par contre prévoit bien un délai, qui est plus long que le délai prévu au Code civil. Le délai qui s'applique aux rachats est celui mentionné dans le Code flamand du logement.

(Décision du 26.03.2009 - EE/103.075)

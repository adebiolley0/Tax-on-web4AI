# Numéro E 46bis-VL/11-01

Numéro E 46bis-VL/11-01

Répertoire RJ – Droits d’enregistrement, d’hypothèque et de greffe

RÉGION FLAMANDE

Numéro E 46 bis -VL/11-01

11. – Amende pour perte de l'abattement - Combinaison avec l'application de l'article 212.

01. - La restitution en application de l' article 212 C. enr . a une répercussion sur l'amende non encore payée de l' article 46 bis C. enr . L'amende due ne peut seulement être calculée qu'en fonction du montant des droits qui est finalement dû sur l'acte.

Les droits complémentaires suite à la perte de l'abattement ne sont pas complètement apurés par la restitution qui y est corrélative. L'amende réduite, d'après le barème, doit être calculée en fonction des droits complémentaires sur l'abattement qui restent maintenus, à savoir 2/5 des droits complémentaires originaux.

La compensation de dette qui est appliquée entre les droits complémentaires et les droits à restituer n'a aucune influence sur le montant de l'amende due.

Exemple 1

Acquisition d'une habitation en 2007 pour le prix de 75.000 EUR . Perçu : (75.000 - 15.000) x 10 % = 6.000 EUR

Revente dans les 2 ans de l'acquisition ; la condition pour le maintien de l'abattement n'est pas respectée.

Conséquences de la revente :

| - | Droits complémentaires article 46 bis C. enr . : 15.000 x 10 % = 1.500 |  |  |
| --- | --- | --- | --- |
| - | Restitution article 212 C. enr . : 75.000 x 10 % x 3/5 = 4.500 |  |  |
| - | Amende article 46 bis C. enr . : |  |  |
|  | Droits complémentaires | Droits à restituer | Amende |
|  | 1.500 | 1.500 x 3/5 = 900 | (1.500-900) x ½ = 300 |

A restituer en final : 4.500 - (1.500 + 300) = 2.700 EUR

Exemple 2

Acquisition d'une habitation modeste en 2007 pour le prix de 75.000 EUR .

Perçu : (75.000 - 15.000) x 5 % = 3.000 EUR

Revente dans les 2 ans de l'acquisition ; non-respect de l'obligation d'inscription et la condition pour le maintien de l'abattement n'est également pas respectée.

Conséquences de la revente :

| - | Droits complémentaires : |  |  |  |
| --- | --- | --- | --- | --- |
|  | article 61 1 C. enr . : 60.000 x 5 % = 3.000 |  |  |  |
|  | article 46 bis C. enr . : 15.000 x 10 % = 1.500 |  |  |  |
| - | Restitution article 212 C. enr . : 75.000 x 10 % x 3/5 = 4.500 |  |  |  |
| - | Amendes |  |  |  |
|  | Droits complémentaires | Droits à restituer | Amende |  |
|  | article 61 1 C. enr . | 3.000 | - 3.600 | 0 |

A recouvrer en final : (4.500 + 300) - 4.500 = 300 EUR.

(Décision du 15.03.2007 - EE/102.016)

Exemple 3

Acquisition d’une habitation modeste en 2011 pour le prix de 75.000 EUR

Perçu : (75.000 – 15.000 – 20.000) à 5% = 2.000 EUR.

Revente endéans les deux ans pour le prix de 80.000 EUR ; non-respect de l’obligation d’inscription et la condition pour le maintien de l’abattement et de l’abattement majoré n’a pas été respectée.

Conséquences de la revente :

- Droits complémentaires :

| Article 61 1 C. enr . : Article 46 bis C. enr . | ((75.000 – 15.000 – 10.000) x 10 %) – 2.000 - abattement : 15.000 x 10 % - abattement majoré : 10.000 x 10 % | = = = | 3.000 1.500 1.000 5.500 |
| --- | --- | --- | --- |

- Restitution article 212 C. enr . : 75.000 x 10 % x 3/5 = 4.500

- Amendes :

|  | Droits Complém . | Droits à restituer | Amendes |
| --- | --- | --- | --- |
| art. 61 1 C. enr . : | 3000 | 3.000 | 0 |
| art . 46 bis C. enr . : |  |  |  |
| - abattement : | 1.500 | 900 | (1.500 – 900) x ½ = 300 |
| - abattement majoré : | 1.000 | 600 | (1.000 – 600) x ½ = 200 |
|  | + 5.500 | - 4.500 | + 500 |

A recouvrer en final : 5.500 - 4.500 + 500 = 1.500 EUR.

(Décision du 0 9.08. 2 012 - EE/104.982)

# Numéro E 199/24-01

Numéro E 199/24-01

Répertoire RJ – Droits d’enregistrement, d’hypothèque et de greffe

Numéro E 199/24-01

24. – Frais de l'expertise de contrôle.

01. - Le Code des droits d'enregistrement ne prévoit rien pour le règlement des contestations concernant les frais de l'expertise de contrôle. Le droit commun est donc applicable. Le juge de paix du ressort dans lequel ce rapport d'expertise a été déposé est compétent pour évaluer les frais.

Dans le cadre d'une instance entre l'Etat et un contribuable, le montant des frais d'expertise ne peut pas être contesté.

(Jugement du tribunal de première instance de Gand du 15.10.1991 - EE/90.307)

# Numéro S 142^1/09-02

Numéro S 142-1/09-02

Répertoire RJ – Droits de succession

Numéro S 142 1 /09-02

09. – Compétence du juge - Evaluation d'actif omis.

02. - Le tribunal n'est pas compétent pour vérifier si l'estimation d'un actif omis, telle qu'elle est portée dans une contrainte décernée, est fondée.

Le seul moyen de défense contre la taxation est le dépôt d'une déclaration régulière réparant l'omission.

(Jugement du tribunal de première instance d'Anvers du 16.01.1976, Rec. gén . enr . not ., n° 22.125 - EE/82.866)

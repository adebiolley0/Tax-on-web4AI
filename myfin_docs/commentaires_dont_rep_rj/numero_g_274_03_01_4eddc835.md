# Numéro G 274/03-01

Numéro G 274/03-01

Répertoire RJ – Droits de greffe

Numéro G 274/03-01

03. – Relation de l'enregistrement.

01. - La relation de l'enregistrement reproduite dans une copie ou une expédition ne doit pas être considérée comme un acte séparé ; mais, pour calculer le nombre de pages qui contient le document reproduit, il faut tenir compte, le cas échéant, de la page utilisée pour apposer cette relation.

( Décision du 05.06.1963 - EE/76.782 )
